MIT License v6.29.3 · Gwendal Roué

SQLite

Public Domain macOS 시스템 라이브러리

세상에서 가장 널리 쓰이는 임베디드 데이터베이스. GRDB를 통해 macOS에 내장된 SQLite를 사용합니다. sqlite.org

Apple 시스템 프레임워크

macOS SDK

그 외 기능은 모두 macOS에 내장된 Apple 프레임워크로 구현했습니다 — SwiftUI·AppKit(인터페이스), ImageIO·CoreImage(디코딩·편집), PhotoKit(Apple Photos 연동), MapKit(지도), QuickLook(미리보기), CryptoKit(캐시 키) 등. 별도 라이선스 고지가 필요한 서드파티 코드는 위 목록이 전부입니다.
