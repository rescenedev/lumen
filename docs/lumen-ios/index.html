틴더처럼 가볍게

🛟

중간에 멈춰도 안전

보관은 누르는 즉시 Lumen 앨범에 저장돼 앱이 꺼져도 남아요. 이미 정리한 사진은 다시 안 나와서, 언제든 이어서 할 수 있어요.

🛡️

실수로 안 지워져요

✕는 ‘삭제 후보’일 뿐. 실제 삭제는 마지막에 시스템 확인을 거쳐 한 번에. 그 전엔 사진이 사라지지 않습니다.

정리 흐름

고르고, 넘기고, 정리 끝

1

묶음 고르기

전체 · 즐겨찾기 · 최근 · 스크린샷, 또는 앨범별로. 정리할 묶음을 하나 선택.

2

넘기며 둘러보기

좌우로 편하게 구경. 위로 올리면 즐겨찾기.

3

고른 것만 정리

남길 건 ♥(Lumen 보관), 지울 건 ✕(삭제 후보).

4

확인 후 마무리

요약에서 보관·삭제 수를 확인하고, 삭제는 한 번에 안전하게.

시작하기

직접 빌드해서 써보기

아직 App Store 배포 전이에요. 소스에서 직접 빌드해 폰에 올릴 수 있습니다 — 무료 Apple ID면 충분.

Xcode로 내 폰에 설치

  1. git clone 후 cd ios && xcodegen generate
  2. LumenIOS.xcodeproj를 Xcode로 열기
  3. Signing & Capabilities에서 본인 Apple ID 팀 선택
  4. 아이폰 연결 → ⌘R → 첫 실행 시 설정에서 개발자 신뢰
