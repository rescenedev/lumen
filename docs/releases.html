0.5.5

2026년 7월 29일최신

대용량 폴더 추가가 바로 반응합니다

  • NAS의 3만 장짜리 폴더를 추가해도 사진이 곧바로 나타나기 시작합니다. 예전에는 폴더 전체를 다 읽을 때까지(SMB에서 수 분) 아무것도 보이지 않았습니다. 이제 폴더 단위로 결과를 넘겨받아 그리드가 차오르고, 찾은 장수가 실시간으로 올라가며, 언제든 중단할 수 있습니다.
  • 같은 폴더를 다시 추가하거나 다음 실행 때 전체를 다시 훑지 않습니다. 추가 시점에 폴더 수정시각을 기록해 두므로, 파일 하나하나를 다시 확인하는 네트워크 왕복이 사라집니다.
  • 백그라운드 작업이 "전체 중 얼마"를 보여줍니다. 썸네일 캐싱과 메타데이터 인덱싱이 남은 개수만 세는 대신 진행 막대와 함께 12,340 / 30,124 형태로 표시됩니다.
  • 임포트 중에도 앱이 멈추지 않습니다. 파일시스템 조회와 라이브러리 병합을 메인 스레드 밖으로 옮겼고, 임포트가 도는 동안 폴더 감시 재스캔이 대역폭을 두고 다투지 않도록 보류됩니다.

0.5.4

2026년 7월 18일

즐겨찾기·태그·라벨 진입이 즉시

  • 즐겨찾기 · On This Day · 라벨 · 태그 · 앨범 · 중복 화면에 들어갈 때의 멈칫(수만 장 기준 ~0.1초)을 없앴습니다. 멤버십 스캔을 백그라운드로 옮겨 진입이 즉시 반응하고, 컬링 중 즐겨찾기/별점을 연타해도 더는 그때마다 멈추지 않습니다 — 실측 94ms → 0.09ms.
  • 성능 회귀를 릴리스마다 자동 검증하는 인앱 계측 프로브를 내장했습니다(개발용, 평소엔 완전 비활성). 랜딩 페이지 벤치마크도 이 프로브의 v0.5.3+ 실측값입니다.

0.5.3

2026년 7월 17일

썸네일 캐시가 다시는 리셋되지 않습니다 · 빈 칸 대신 즉시 표시

  • 썸네일 저장소를 macOS가 지우지 못하는 위치로 옮겼습니다. 저장공간이 부족하거나 정리 앱을 쓰면 시스템이 캐시 폴더를 통째로 비워 수만 장 썸네일을 처음부터 다시 만들던 문제의 근본 해결입니다. 기존 캐시는 자동으로 이전됩니다.
  • 캐시가 없는 사진도 빈 회색 칸 대신 바로 보입니다. 사진에 내장된 미리보기를 먼저 그리고(파일 헤더만 읽음), 선명한 썸네일이 준비되면 교체합니다 — 아이폰 HEIC에서 특히 체감이 큽니다.
  • 라이브러리를 다른 드라이브로 옮긴 뒤 남는 옛 캐시 찌꺼기(수 GB)를 하루 한 번 자동 정리합니다. 새로 만든 캐시·끊긴 드라이브의 캐시는 건드리지 않습니다.

0.5.0

2026년 6월 27일

성능 대폭 개선 · 데이터 안전 강화

  • 편집·삭제·정리 후 끊김 제거. 즐겨찾기/별점/삭제 직후 사이드바·폴더·검색이 멈칫하던 것을 없앴습니다(파생 데이터를 백그라운드에서 다시 계산). 사진을 하나씩 골라 지우는 작업도 매끄럽습니다.
  • 스크롤이 더 매끄럽게. 썸네일 디코드를 메인 스레드 밖으로 옮기고, NAS를 처음 빠르게 훑을 때 화면 밖으로 사라진 셀의 디코드가 지금 보이는 셀을 막던 문제를 고쳤습니다.
  • 뷰어 넘김이 빨라졌습니다. 보고 있는 사진이 이웃 사진 미리읽기 뒤에 밀리지 않도록 처리 경로를 분리했습니다.
  • 실행 후 검색·지도·카메라 필터가 ~0.5초 빨리 준비됩니다(EXIF 캐시를 빠른 바이너리 형식으로 전환).
  • 데이터 안전 강화. 중복 찾기 오탐(고유 사진을 삭제할 위험)을 막고, NAS 일시 장애 때 폴더가 통째로 사라지던 문제와 라이브러리 지우기가 재시작 시 되살아나던 문제를 고쳤습니다. 편집·내보내기 시 촬영 날짜·위치(EXIF/GPS)도 보존됩니다.
  • 대용량 라이브러리 정확성. 정렬이 끝난 뒤 지도 핀·선택 순서·삭제 후 선택이 옛 상태를 보여주던 문제를 고쳤습니다.

0.4.0

2026년 6월 12일

삭제 안전망 — NAS에서도 되돌릴 수 있습니다

  • 휴지통 없는 볼륨(NAS/SMB)에서도 삭제가 영구가 아닙니다. 같은 볼륨의 숨김 .LumenTrash 폴더로 이동하고(이동은 즉시), 30일 뒤 자동 정리됩니다.
  • 모든 삭제 직후 10초간 "되돌리기" 버튼. 파일은 물론 즐겨찾기·별점·앨범 소속까지 원위치로 복원합니다.

크래시 리포팅 — 프라이버시 그대로

  • 크래시가 나면 버전·OS·스택만 담긴 리포트를 내 Mac에만 저장하고, 다음 실행에 GitHub 이슈로 보낼지 물어봅니다. 직접 선택하기 전에는 아무것도 전송되지 않습니다 — 파일 경로나 사진 정보는 리포트에 아예 들어가지 않습니다.

성능 — 대량 작업

  • 즐겨찾기/별점/라벨/태그 일괄 적용이 단일 트랜잭션으로. 20,000장 즐겨찾기 0.4초 (기존: 사진당 커밋 1개로 수 분).
  • 삭제·되돌리기·일괄 이름변경·내보내기의 파일 작업이 전부 백그라운드로 — NAS에서 수백 장을 처리해도 UI가 멈추지 않습니다.
  • 폴더 이름변경 시 60k 라이브러리에서 수 분간 멈출 수 있던 경로 재계산 제거.

고침

  • NAS 스캔 도중 삭제/되돌리기를 하면 결과가 뒤집힐 수 있던 동기화 레이스.
  • 장시간 EXIF 인덱싱 중 삭제한 사진의 정보가 되살아나던 문제.
  • 설정의 슬라이드쇼 간격이 실제로 적용되고, 기본 정렬이 재실행 후에도 유지됩니다.
  • 메타데이터 저장 실패(디스크 부족 등)가 조용히 무시되지 않고 알림으로 표시됩니다.
  • 뷰어를 처음 열면 컬링 단축키(Space/X/1–5) 안내가 한 번 표시되고, 알림 메시지가 시스템 언어(영어/한국어)를 따릅니다.

67,676장 라이브러리 기준, 프레임 단위로 측정하며 시작 경로를 다시 설계했습니다.

0.3.4

2026년 6월 12일

성능

실제 67,676장 NAS 라이브러리에서 측정하며 수정한 대규모 성능 배치입니다.

  • 사진 선택이 즉각 반응합니다. 클릭당 인스펙터 갱신 ~70ms → ~3ms, 전체 선택(⌘A, 6.7만 장)은 0.8초 멈춤 → 0.2초.
  • 검색이 더 이상 화면을 멈추지 않습니다. 큰 라이브러리에서 검색 1회당 ~0.4초씩 메인 스레드를 막던 필터링이 정렬과 함께 백그라운드에서 돕니다.
  • 실행 후 ~40초쯤 발생하던 3~4초 프리즈를 제거했습니다. 라이브러리 동기화(reconcile)와 썸네일 캐시 워밍 스캔이 메인 스레드를 막고 있었습니다.
  • 썸네일 크기 슬라이더·창 크기 조절이 부드러워졌습니다. 그리드 썸네일이 GPU로 스케일되어 틱당 ~350ms 걸리던 재드로우가 사라졌습니다.
  • 리스트 보기를 네이티브 테이블로 교체했습니다 — 수만 행에서도 즉시 열리고, 대량 선택이 약 5배 빨라졌습니다.
  • 실행 직후 첫 폴더 클릭 156ms → 4ms, 첫 검색·실행 직후의 잔 끊김도 인덱스 사전 계산으로 줄였습니다.

0.3.3

2026년 6월 10일

고침

  • NAS 볼륨에서 사진 삭제가 실제로 동작합니다. SMB 공유에는 휴지통이 없어 삭제가 조용히 실패했는데, 이제 Finder처럼 "즉시 삭제됩니다" 경고 후 삭제합니다. NAS 쪽 휴지통(예: Synology #recycle)이 켜져 있으면 거기서 복구할 수 있고, 실패하면 토스트로 알려줍니다.
  • ⌫/⌦ 키 삭제가 뷰어·리스트·월별 보기에서도 동작합니다.
  • 폴더를 전환하면 항상 맨 위에서 시작합니다. 같은 폴더에서 삭제·추가할 때는 보던 위치를 유지합니다.
  • 하위 폴더가 있는 폴더도 한 번 클릭으로 정확히 선택(액센트 색)되고 하위 폴더가 매번 펼쳐집니다. 다시 클릭하면 접힙니다.
  • 손상된 이미지 파일(0으로 채워진 복사 실패본)은 경고 표시로 보여줍니다 — 일반 JPEG 아이콘으로 위장하거나 썸네일 캐시를 오염시키지 않습니다.

신규

  • 창을 닫아도 종료되지 않습니다. 썸네일 캐시 워밍이 초저속(CPU 1% 미만, 몇 초당 1장)으로 계속되고, 창을 다시 열면 원래 속도로 복귀합니다. ⌘Q는 평소처럼 완전 종료합니다.

0.3.1

2026년 6월 10일

성능

  • 썸네일 로드 시 원본 파일 조회(stat)를 제거 — 스크롤 중 사진 한 장당 NAS 왕복 1회를 절감합니다.
  • 스크롤 방향을 따라가는 뷰포트 기반 프리페치 — 전체 목록을 미리 디코드하지 않습니다.
  • 2단 썸네일 캐시: 작은 그리드 셀은 256px 티어를 사용해 메모리 캐시에 약 4배 많은 썸네일이 들어갑니다 (촘촘한 그리드에서 캐시 스래싱 제거).
  • 월별 타임라인이 다시 그릴 때마다 라이브러리 전체를 재그룹핑하지 않습니다.
  • 큰 앨범도 다른 보기처럼 메인 스레드 밖에서 정렬합니다.
  • 백그라운드 캐시 워밍이 지금 보고 있는 폴더부터 시작합니다.

고침

  • 사이드바에서 하위 폴더가 있는 폴더도 단일 클릭으로 선택됩니다.
  • 그리드 ←/→ 키가 행 끝에서 다음/이전 행으로 이어집니다 (Finder 스타일).

0.3.0

2026년 6월 8일

신규 — 자동 업데이트 알림

  • 실행 시 새 버전을 자동 확인(하루 1회)하고, 새 버전이 있으면 상단 배너로 알려줍니다. 메뉴의 Check for Updates…로 수동 확인도 가능합니다.
  • Homebrew 설치본에는 업그레이드 명령을, 직접 다운로드본에는 릴리즈 페이지를 안내합니다 (자동 설치는 하지 않아 Homebrew 버전 추적과 충돌하지 않습니다).
  • cask에 livecheck 추가 — brew outdated / brew upgrade가 새 버전을 안정적으로 감지합니다.
