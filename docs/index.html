Lumen

대용량 사진 라이브러리를 가볍게 — macOS 네이티브 뷰어 & 매니저

🖼️ 편집 없는 뷰어· ⚡ 6만 장+ NAS 대응· 🦅 SwiftUI

⬇️ 다운로드 GitHub에서 보기
brew tap rescenedev/tap brew install --cask lumen-photos

필요한 건 다, 무거운 건 없이

사진을 보고 정리하는 데 필요한 기능만 — 픽셀 편집 없는 안전한 뷰어/매니저.

🗂️

그리드 · 리스트 · 지도

적응형 썸네일 그리드, 상세 리스트, GPS 사진을 지도 핀으로. ⌘1·2·3로 전환.

📁

폴더 트리 & 스마트 모음

계층형 폴더, 즐겨찾기·최근 추가·오늘 날짜·중복 찾기. 폴더 우클릭으로 이름변경·앨범화.

🏷️

앨범 · 태그 · 별점 · 라벨

비파괴 메타데이터로 정리. Space로 즐겨찾기 후 바로 다음 사진 — 빠른 컬링.

🔍

검색 & 필터

파일명·태그·카메라 검색. 별점·라벨·위치·카메라(예: SONY)로 필터.

👁️

몰입형 뷰어

줌·팬, 좌우 썸네일 미리보기, EXIF 오버레이, 2장 비교, 슬라이드쇼.

📤

공유 · 내보내기

시스템 공유, 원본/리사이즈/zip 내보내기, 배경화면 설정, 일괄 이름변경.

대용량 라이브러리를 위해 설계

NAS에 흩어진 수만 장도 휙휙. 한 번 캐싱하면 어느 폴더든 즉시.

60K+
장 라이브러리 실사용 테스트
2-tier
메모리+디스크 썸네일 캐시 (재실행에도 유지)
즉시
증분 스캔·캐시로 빠른 재실행

메모이즈된 목록 · 폴더 인덱스 · 디바운스 내비게이션 · 백그라운드 전체 썸네일 워밍 · 지연 EXIF 인덱싱

설치

brew tap rescenedev/tap brew install --cask lumen-photos
macOS 14(Sonoma) 이상. 노타라이즈되지 않은 빌드라, 첫 실행 시 Gatekeeper가 막으면 앱을 우클릭 → 열기 하거나 아래를 실행하세요:
xattr -dr com.apple.quarantine "/Applications/Lumen.app"
소스로 빌드: git clone 후 ./Scripts/make_app.sh (Xcode 불필요, Command Line Tools만)
